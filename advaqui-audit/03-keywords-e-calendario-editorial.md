## 4. Padrão de Artigo Otimizado

Cada artigo novo segue este template para maximizar SEO + retenção do leigo:

```
1. H1: pergunta natural do usuário (ex: "Fui demitido sem justa causa, e agora?")
2. Box de metadados visível: data + autor (OAB) + tempo de leitura
3. Caixa de resumo: "TL;DR — 3 bullets do que você vai aprender"
4. Sumário clicável (ancoragem interna)
5. Introdução (problema do leigo, não definição técnica)
6. Fluxograma visual (ou tabela) — ativo embedável
7. H2s temáticos (4–7 seções)
8. CTA intercalado #1: "📥 Baixe o kit [tema]" (a 35% do scroll)
9. Lista de erros comuns / armadilhas
10. CTA intercalado #2: "Encontre advogado em [cidade detectada por geoIP]" (a 70%)
11. FAQ (6–10 perguntas) com schema FAQPage
12. Box "Quando procurar um advogado"
13. Box do autor (foto, OAB, bio, outros artigos)
14. Artigos relacionados (3–5)
15. Compartilhamento social fixo (WhatsApp prioritário)
16. Comentários / "tire sua dúvida" (UGC = SEO infinito)
```
